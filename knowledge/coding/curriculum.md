# FigoAI Programming Curriculum

This reference map tells FigoAI what coding domains it should be prepared to teach and connect across subjects.

## Web foundations
HTML: document structure, semantic elements, forms, validation, accessibility, metadata, media, tables, links, and browser APIs.
CSS: selectors, cascade, specificity, inheritance, box model, display, positioning, flexbox, grid, responsive design, media queries, transitions, animations, variables, typography, and modern component styling.
JavaScript: variables, types, operators, functions, scope, closures, arrays, objects, classes, modules, promises, async/await, DOM, events, fetch, errors, storage, browser APIs, testing, and performance.
TypeScript: types, interfaces, unions, generics, narrowing, utility types, modules, decorators where applicable, configuration, and safe API design.

## Frontend frameworks
React: components, JSX, props, state, hooks, effects, context, refs, forms, routing concepts, data fetching, performance, testing, and architecture.
Vue: templates, directives, components, props, emits, reactivity, computed values, watchers, Composition API, routing concepts, state management, testing, and build tooling.

## Backend
Node.js: runtime concepts, modules, npm, HTTP servers, Express-style APIs, middleware, validation, authentication, authorization, streams, files, workers, testing, and deployment.
Python: syntax, data structures, functions, classes, modules, virtual environments, exceptions, typing, async programming, testing, web APIs, automation, data processing, and scientific/ML ecosystems.
Java: classes, interfaces, inheritance, generics, collections, exceptions, streams, concurrency, JVM concepts, testing, and server applications.
C: memory, pointers, arrays, strings, structs, functions, headers, compilation, linking, files, processes, and debugging.
C++: RAII, references, classes, templates, STL, smart pointers, move semantics, exceptions, concurrency, and modern C++ practices.

## Data and systems
SQL: relational modeling, SELECT, filtering, joins, grouping, subqueries, CTEs, window functions, transactions, indexes, constraints, normalization, and query optimization.
Git: repositories, commits, branches, merges, rebases, remotes, pull requests, conflict resolution, and recovery.
Linux: shell basics, processes, permissions, filesystems, networking, packages, services, logs, and automation.
Docker: images, containers, Dockerfiles, volumes, networks, Compose, environment configuration, and deployment.

## Algorithms and data structures
Arrays, linked lists, stacks, queues, hash tables, trees, heaps, graphs, recursion, sorting, searching, traversal, dynamic programming, greedy algorithms, complexity analysis, and practical tradeoffs.

## Machine learning and AI
Linear algebra basics, probability, statistics, datasets, preprocessing, train/validation/test splits, regression, classification, clustering, feature engineering, neural networks, optimization, evaluation, overfitting, transformers, embeddings, retrieval-augmented generation, model serving, inference, and responsible AI engineering.

## Engineering practice
APIs, REST concepts, HTTP, JSON, authentication, authorization, validation, logging, observability, testing, debugging, security fundamentals, dependency management, CI/CD, deployment, performance, maintainability, code review, and documentation.

When answering coding questions, FigoAI should prefer current, runnable examples and explicitly state assumptions when a framework or library version matters.
